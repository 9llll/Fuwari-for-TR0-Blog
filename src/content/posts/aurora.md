一套纯 PHP + MySQL 编写的完整「应用市场 / APP 下载站」整站源码，仿主流应用市场风格，

含前台用户站 + 后台管理系统 + 支付系统，图形化安装向导，宝塔一键部署，开箱即用。

一、前台功能

首页：轮播图、热搜词、分类导航、热门推荐、最新上架、高分应用、下载排行榜

手机端底部悬浮菜单栏（分类/排行/首页/会员/我的），滑动指示器、图标弹跳、水波纹动效，移动端体验完善

分类页：综合/最热/评分/最新/价格排序，免费/付费筛选，分页加载

搜索：应用名 / 简介 / 开发者 模糊搜索

排行榜：下载榜 / 好评榜 / 新品榜 / 付费热销榜

应用详情：沿用仿应用市场下载页样式，星级分布、评论列表、发表评论打分（一人一评可更新）、收藏

登录 / 注册 / 退出，CSRF 防护、bcrypt 密码加密

下载权限：免费应用直接下；付费应用需购买；VIP 会员免费下；安装包经鉴权后输出（隐藏真实路径），自动统计下载量

个人中心：资料修改、订单、已购应用、收藏、我的评论、修改密码

VIP 会员：套餐开通，到期时间顺延累加

二、支付系统（易支付 / 彩虹易支付）

单应用购买 + VIP 开通，支持支付宝 / 微信 / QQ钱包 / 云闪付

待支付订单自动复用、支付结果页自动查单、异步回调幂等发货、金额校验

后台可手动补单、退款（查单 / 退款接口齐全）

三、后台管理（/admin/）

仪表盘：用户/应用/订单/收入统计、最新订单、待审评论

应用管理：增删改查、图标/多截图/APK 上传、定价、上下架、首页推荐

分类管理：内置 200+ 常用 Font Awesome 图标库，点击即选即复制

轮播图管理、会员套餐管理

评论审核：通过/隐藏/删除，评分自动重算

订单管理：筛选、查单补单、退款

用户管理：设管理员、封禁、设 VIP 到期、重置密码、删除

站点设置：站名、网站 Logo 上传/恢复默认、公告、热搜词、ICP、评论审核开关、站点地址、易支付参数
